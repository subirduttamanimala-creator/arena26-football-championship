# ARENA 26 — Football Championship

A responsive, front-end prototype for a fictional inter-college football championship.

## Run locally
1. Extract the project ZIP.
2. Open this folder in Visual Studio Code.
3. Open `index.html` with Live Server (or open the file in a browser).
4. Keep the folder structure unchanged so the CSS, JavaScript and image paths resolve.

## Project structure
- `index.html` — page structure and content
- `css/style.css` — layout, colors, responsive design and components
- `js/script.js` — team directory, filters, schedule tabs, countdown, registration demo and CSV export
- `images/` — local SVG logo and football-themed graphics
- `screenshots/` — desktop/mobile preview images

## Prototype behavior
- 40 fictional section slots: 10 sections (A–J) in each of Years 1–4.
- Registration form saves demo entries in the current browser's local storage.
- CSV export downloads demo entries saved in that browser.
- Filters and schedule tabs are interactive.
- No backend, database, authentication, email or shared organizer dashboard is connected.

## Before publishing
Replace the sample dates, teams, fixtures, eligibility rules and contact information with college-approved details. Do not use the local demo form to collect real student personal data. A real registration system needs a backend and appropriate access controls.
